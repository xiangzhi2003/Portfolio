# Chiang Xiang Zhi — Portfolio

Personal portfolio site built with plain HTML, CSS and JavaScript. Deployed on Vercel.

Live: https://chiangxiangzhi.vercel.app

## Structure

```
.
├── src/
│   ├── index.html
│   ├── css/styles.css
│   ├── js/script.js
│   ├── assets/
│   │   ├── fonts/
│   │   ├── images/      profile, textures, log, logos, projects
│   │   └── docs/        resume PDF
│   ├── favicon.ico
│   ├── robots.txt
│   └── sitemap.xml
├── vercel.json
└── LICENSE
```

## Run locally

```bash
git clone https://github.com/xiangzhi2003/Portfolio.git
cd Portfolio
npx serve src
```

Then open http://localhost:3000.

## Deployment

Pushes to `master` deploy automatically via Vercel. `vercel.json` serves the
`src` folder with no framework and no build step.
